# 📚 Indeks Dokumentasi — SAPA (Sistem Asisten Pantau Aktif)

Selamat datang di repositori dokumentasi resmi proyek **SAPA**. Seluruh panduan, dokumen kebutuhan produk, arsitektur teknis, dan petunjuk penilai juri dirangkum dalam folder ini:

---

## 📑 Daftar Dokumen

| Dokumen | Deskripsi |
|---|---|
| [**Panduan Penilaian Juri (`PANDUAN_JURI.md`)**](PANDUAN_JURI.md) | **Wajib dibaca oleh juri & evaluator.** Berisi panduan 1-klik mode demo, 6 skenario pengujian fitur unggulan (pemutar suara nenek, simulasi kejang & getar, kontras warna, pengingat obat, pengaturan, dan ekspor CSV). |
| [**Arsitektur Teknis (`ARSITEKTUR.md`)**](ARSITEKTUR.md) | Diagram alur sistem (Mermaid), entity relationship database (Prisma & Supabase), pemrosesan multimodal AI suara, serta arsitektur keamanan sesi HMAC-SHA256. |
| [**Spesifikasi Produk (`PRD.txt`)**](PRD.txt) | Dokumen Product Requirement Document (PRD) asli yang mendasari perancangan platform pemantauan lansia. |
| [**Panduan Setup Database (`supabase.md`)**](supabase.md) | Panduan instalasi Supabase, konfigurasi pooling koneksi, dan eksekusi skrip RLS/indeks. |
| [**Galeri Tangkapan Layar (`screenshots/`)**](screenshots/) | Dokumentasi visual antarmuka pengguna dari layar depan, app lansia, dashboard keluarga, hingga mode split-screen demo. |
